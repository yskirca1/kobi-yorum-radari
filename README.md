# ReviewRadar

Satmak istediğin ürünün kategorisini ara; rakip ürünlerin müşteri yorumlarından çıkan en büyük şikâyetleri, müşterinin neyi sevdiğini ve bu pazara girerken nelere dikkat etmen gerektiğini gör.

Hamilik Okulu Vakfı pazarlama projesi. Veriler Trendyol'daki herkese açık ürün sayfalarından toplanmıştır.

- `index.html`, `style.css`, `app.js`: site
- `data/kategoriler.json`: kategori listesi
- `data/<kategori>.json`: kategori verisi (ürünler, şikâyet ve olumlu konu oranları, notlar, alıntılar)
